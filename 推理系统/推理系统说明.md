# 推理系统（Inference System）
更新时间：2026-7-19

## 1. 概述

推理系统主要研究如何高效地运行大规模模型，并通过系统优化提升推理性能、降低资源消耗。

当前主要参考vLLM/sglang推理框架开展
重点围绕以下方向：
-   模型结构
-   模型并行
-   CUDA 算子优化
进行深度探索

## 2. 整体结构

    推理系统

    ├── 模型结构（Model Architecture）
    │
    ├── 模型并行（Model Parallelism）
    │
    ├── CUDA 算子（Kernel Optimization）
    │
    ├── 推理框架（Inference Framework）
    │
    └── 高级机制（Advanced Mechanism）

## 3. 模型结构

研究张量数据在不同模型中的转换流程；梳理模型各个模块的设计思想；描绘模型的演进和迁移过程

主要内容：
-   Transformer
-   Attention
-   GQA / MLA
-   MoE

核心问题：
1. 研究张量数据在不同模型中的转换流程
2. 模型结构如何影响计算量、显存占用以及推理效率？

## 4. 模型并行

关注如何将大模型拆分到多个 GPU 上运行。

主要内容：

-   Tensor Parallelism (TP)
-   Pipeline Parallelism (PP)
-   Data Parallelism (DP)
-   Expert Parallelism (EP)

核心问题：

> 如何利用多 GPU 提升模型规模和推理吞吐？

## 5. CUDA 算子

关注 GPU 底层计算优化。

主要内容：

-   CUDA
-   Triton
-   FlashAttention
-   Attention Kernel

核心问题：

> 如何优化 GPU 计算，提高单算子执行效率？

## 6. 推理框架

关注工业级推理系统的设计与实现。

主要框架：

-   vLLM
-   SGLang

主要关注：

-   系统架构
-   Scheduler
-   Memory Management
-   Runtime
-   Source Code

核心问题：

> 如何将模型、GPU 资源和请求调度结合，构建高性能推理服务？

## 7. 高级机制

关注推理系统中的其他关键优化机制。（只作了解和梳理）

主要内容：

-   KV Cache 管理
-   Prefix Cache
-   Chunked Prefill
-   Speculative Decoding
-   PD Disaggregation
-   Dynamic Scheduling

核心问题：

> 如何进一步提升推理系统的资源利用率和服务性能？
