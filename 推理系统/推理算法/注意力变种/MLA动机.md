# MLA动机：共享下投影与低秩压缩

> 本文是「注意力变种」系列的专题篇，回答一个问题：**MLA 为什么把 K/V 的生成路径改成「共享下投影 + 低秩压缩」，这个设计从哪来？** 它是 [MLA.md](MLA.md) 的动机篇——那篇讲「怎么运转」，本文讲「为什么这么设计」：MQA/GQA 共享投影的困境、低秩分解的思想谱系，以及两者在共享下投影上的合流。
>
> 关联：[MLA](MLA.md)（机制篇）、[注意力变种概述](注意力变种概述.md) §3、[MHA](MHA.md)（共同基准）。

---

# 0. 符号约定

```text
H    : 隐藏维度
N    : 头数
d    : 每头维度，d = H / N
d_c  : KV 压缩潜维度（latent dim），d_c ≪ N·d
X    : token 隐状态，[S, H]
```

---

# 1. 冗余的根源：K 和 V 来自同一个 X

MHA 中 K、V 的生成是两条独立满秩投影：

```text
K = X · Wk      Wk : [H, N·d]
V = X · Wv      Wv : [H, N·d]
```

注意两份投影的**输入是同一个 X**——同一个 token 的 K 和 V，本质是同一隐状态的两个视角，携带的语法/语义/指代信息高度重叠。两份 `[H, N·d]` 满秩投影天然携带大量冗余，这就是压缩空间的来源。同时 KV Cache 为 `2·N·S·d`，随头数线性膨胀。削减它有两个下手处：**份数**（N 份）与**维度**（投影前的 H）——前一条是 MQA/GQA 走的路，MLA 动的是后一条。

---

# 2. 共享投影路线的困境：省份数、损质量

MQA/GQA 共享的是**最终的 K/V（出口处共享）**：MQA 让所有头共用一组 K/V，Cache 缩到 `1/N`；GQA 分 G 组共享，缩到 `G/N`。它们的困境一句话：**共享点放得越靠近出口，省得越多，但头间 K/V 的差异也被抹得越多**——多头的分工（局部邻域头、长程头、语法头）依赖各头 K/V 的多样性，出口共享等于直接削掉这份多样性。省 Cache 与保表达力在「出口共享」框架内是零和的，GQA 只是取折中，没有跳出框架。

---

# 3. 低秩分解思想：参数化换存储

另一条思路来自矩阵分解：`Wk:[H, N·d]` 可以写成两个小矩阵的乘积——

```text
Wk ≈ W_dkv · W_uk        W_dkv:[H, d_c]，W_uk:[d_c, N·d]，秩 ≤ d_c
```

同族先例：LoRA（微调增量 `ΔW = B·A` 因子化）、ALBERT（跨层因子化共享）。核心思想是**用低秩参数化换存储**。应用到注意力：若 K、V 各自独立分解，会得到两个潜变量 `c_K = X·W_dk`、`c_V = X·W_dv`——Cache 变成 `2·S·d_c`，**各自低秩，但仍各存两份**。低秩只解决了「维度」，没解决「份数」。

---

# 4. 合流：把共享点从出口挪到瓶颈

MLA 的关键一步，是把 §2 的「共享」与 §3 的「低秩」拼在一起：**K 和 V 不各自分解，而是共用同一个下投影 `W_dkv`**——先压成一份 `c_KV`，过瓶颈之后再用两个独立上投影各自还原：

```text
                  ┌── K = c_KV · W_uk     （每头独立的 K）
X ──W_dkv──> c_KV ┤
                  └── V = c_KV · W_uv     （每头独立的 V）
```

两条路线的对照：

| 路线     | 共享点         | 省的是什么       | 代价                       |
| -------- | -------------- | ---------------- | -------------------------- |
| MQA/GQA  | 出口（最终 K/V） | 份数             | 头间 K/V 差异被抹          |
| MLA      | 瓶颈（下投影）   | 维度 + K/V 合一  | 表达空间受秩 `d_c` 约束   |

这等于**存一份、读多路**：Cache 里只有 `[S, d_c]`；K/V 的差异推迟到读取时用不同上投影还原，而上投影又能被权重吸收折进 `W_uq`/`Wo`（见 [MLA.md](MLA.md) §5），读取几乎零额外代价。两头的好处同时拿到：Cache 体量与 MQA 同量级，每个头仍保有自己独立的 K/V——多头多样性不丢。秩 `d_c` 的表达空间约束也不是「先训满秩再压缩」的事后近似，而是训练一开始就在这个参数化内学（§5）。

---

# 5. 训练期架构 vs 推理期技巧：一致性从哪来

**分界线**：`W_dkv`/`W_uk`/`W_uv`/`W_kr` 全部是**训练期端到端学出来的权重**，DeepSeek-V2 从第一轮梯度起就是这个结构；推理侧真正的「技巧」只有权重吸收。这套设计与原生 Transformer 的一致性靠两层保证：

**① 注意力核心原样保留。** 还原出的 K/V 仍是 `[N, S, d]`，每头内照旧 `softmax(Q_i·K_i^T/√d)·V_i`。MLA 改变的只是 K/V 的**参数化方式**：满秩大矩阵 → 秩 `d_c` 的因子乘积。表达空间确实变窄（`Wk = W_dkv·W_uk` 秩 ≤ `d_c`），但约束写进训练、模型在低秩空间内自己找最优——不是训好之后压一压的近似，不存在「还原不准」的一致性债务。

**② 权重吸收是乘法结合律，严格等价。** 推理只是给训练前向换了括号位置：

```text
Q·K^T = (c_Q·W_uq) · (c_KV·W_uk)^T = c_Q · (W_uq·W_uk^T) · c_KV^T
V 侧： softmax·(c_KV·W_uv)·Wo = (softmax·c_KV) · (W_uv·Wo)
```

结合律保证重排前后数学结果完全相同（浮点上仅求和顺序差异），没有任何近似。唯一吸收不动的是 **RoPE**：旋转角 `m·θ` 依赖 token 位置、插在 K 的生成路径中间，无法折成静态矩阵——所以才有了「RoPE 解耦」，把 K 拆成可吸收的 nope 段与单独存储的小维 rope 段（位置编码本身见 [rope.md](rope.md)，解耦在 MLA 的落点见 [MLA.md](MLA.md) §5）。

由此得到一个看整个系列的通用视角：**MQA/GQA/MLA 是训练期架构（权重即证据）；权重吸收、PagedAttention 这类才是推理期工程技巧（代数/内存重排，不改数学）。** 两类东西混在一起出现时，值得刻意区分。

---

# 6. 小结

```text
冗余：  K/V 同源于 X，两份满秩投影天然冗余
困境：  MQA/GQA 出口共享——省份数与多头多样性零和
思想：  低秩分解（LoRA 同族）——参数化换存储，但各自分解仍存两份
合流：  共享下投影——瓶颈共享、出口独立，「存一份、读多路」
一致：  训练期架构（低秩约束写进训练）+ 推理期结合律重排（严格等价）
        RoPE 不可吸收 → 解耦为 nope/rope 两段
```

一句话：**MLA = 把 MQA/GQA「共享省 Cache」的动机与低秩分解「瓶颈参数化」的手段合流——共享点从出口挪到瓶颈，存一份低维潜变量，读出每头独立的 K/V。**
