# 注意力变种概述：MHA / MQA / GQA

> 本文是「注意力变种」系列的开篇。它不深入每种变体的张量细节，只回答四个问题：**什么是注意力变种、为什么会出现、常用类型有哪些、它们和 [自回归生成](<../0-Transformer%20自回归生成的最小闭环.md>) 是什么关系。**
>
> 各变体的详细张量流将放在本目录后续单独文档中。

---

# 1. 问题：单头 Self-Attention 只能提取单一维度特征

在 [自回归生成](<../0-Transformer%20自回归生成的最小闭环.md>) 中，为了突出主线，我们把 Self-Attention 简化为**单头**：一组 `Wq/Wk/Wv`，投影出一组 `Q/K/V`，算一次 Attention。

但单头有一个根本局限：**它只能学出一组 Q/K/V 投影，意味着只能在「一个」语义子空间里建立 token 与 token 之间的关联。** 而一段 Prompt 中 token 间的关系是多维度的——有的关联来自语法结构、有的来自共指/指代、有的来自长程语义依赖、有的来自位置邻近。一组投影很难同时刻画这些彼此正交的关联维度。

既然一组投影不够，自然的想法就是**用多组投影并行**——这就是「分头」的动机。

---

# 2. 什么是「头」：分头与注意力变种

## 2.1 什么是头、为什么要分头

「头」（head）是 Self-Attention 的并行计算单元。**分头，就是把原本一组 `Wq/Wk/Wv` 拆成多组，每个头持有各自独立的 `Wq/Wk/Wv`，投影出各自的 `Q/K/V`，独立做一次 Attention，最后把各头输出拼回去。**

这里需要澄清一个维度：上面说的「拆」，拆的是 **H 维——即隐藏维度（hidden_size），也就是 [自回归生成](<../0-Transformer%20自回归生成的最小闭环.md>) 中每个 token 经 Embedding 后得到的向量长度（`X: [S, H]` 的那个 H）**。分头把 H 维拆成 N 份，每份 `head_dim = H / N`，让每个头在自己的 `head_dim` 维子空间里独立做 Attention。这样模型就能同时从 N 个不同维度去「关注」token 之间的关联，最后拼回融合成完整的 `[S, H]` 表示。

这才是多头（MHA）出现的根因——它服务于模型表达能力，而非工程效率。

## 2.2 训练侧的印证

这一点从**模型训练**中也能看出端倪：训练后的多头往往自发地出现「分工」——某些头稳定地关注局部邻域，某些头关注长程依赖，某些头对特定语法关系敏感。这种自发的维度分化说明，多头并非冗余设计，而是模型对「不同维度关联」需求的直接体现。

## 2.3 注意力变种：头间如何共享 K/V

多头成立后，一个新问题浮现：**这些头之间的 K/V 投影，是各自一份，还是共享？** 对这个问题的不同回答，就构成了**注意力变种**。

换句话说，注意力变种改的不是自回归生成里那条「Q×K^T → Softmax → ×V」的主流程，而是**K/V 在「头」这个维度上的排布方式**——主流程不变，变的只是 K/V 张量在头维度上的形状与体积。MHA（每个头各持一组 K/V）是其中最基础的一种，MQA/GQA 则是让多个头共享 K/V 的变体。

## 2.4 变体（MQA/GQA）的动因：在并行背景下削减 KV Cache

既然多头为表达力而各持一组 K/V，为什么又要共享？因为多头带来了一个工程后果：KV Cache 随头数 N 线性膨胀。自回归生成中单头 KV Cache 是：

```text
K Cache: [S, H]
V Cache: [S, H]
```

变成 MHA 后，每一层、每一步都成为：

```text
K Cache: [N, S, head_dim]
V Cache: [N, S, head_dim]
```

这本身并不致命。真正让「削减 KV Cache」成为显式动机的，是**当多头与多卡并行（TP 切分头）结合后**：每个头各存一份 K/V，使 Decode 阶段的访存量与显存占用成为瓶颈（memory-bound），长上下文与多卡部署的压力被放大。

MQA/GQA 正是在这一背景下出现的变体——**在 MHA 已成立、表达能力已满足的前提下**，通过让多个头共享 K/V 投影来削减 KV Cache 的份数，省显存、加速 Decode、让单卡装下更长上下文。也就是说，减少 KV Cache 是变体的直接目的，但它仍是「多头之上」的附带优化，而非多头本身存在的根因。

一句话区分：**多头为表达力而生，变体为工程效率而生。**

# 3. 常用类型

三种主流变体的区别，可以一句话概括：**K/V 这组投影，是每个头各有一份，还是所有头共用一份，还是折中地分组共用。**

| 变体                                     | K/V 投影份数          | KV Cache 体积（相对 MHA） | 代表模型                       |
| ---------------------------------------- | --------------------- | ------------------------- | ------------------------------ |
| **MHA**（Multi-Head Attention）    | 每个头各一组          | 1×（基准）               | GPT、LLaMA 等多数基座          |
| **MQA**（Multi-Query Attention）   | 所有头共用 1 组       | 1/N                       | PaLM、StarCoder 等             |
| **GQA**（Grouped-Query Attention） | 分成 G 组，每组内共用 | G/N                       | LLaMA-2(部分)/LLaMA-3、Mistral |

- **MHA**：每个头独立持有 `Wk/Wv`，表达力最强，但 KV Cache 体积最大。
- **MQA**：所有头共用同一组 `Wk/Wv`，KV Cache 缩到 1/N，Decode 最省，但表达力损失较明显。
- **GQA**：介于两者之间——把 N 个头分成 G 组，组内共享 `Wk/Wv`。`G=1` 退化为 MQA，`G=N` 退化为 MHA，是目前主流的折中选择。

> 补充：DeepSeek-V2 提出的 **MLA**（Multi-head Latent Attention）走的是另一条路——不靠共享 K/V，而是把 KV 压缩到一个低维潜变量再还原，同样为削减 KV Cache。它属于另一类思路，概述不展开，张量细节见 [MLA.md](MLA.md)，这条路线为什么出现、「共享下投影」的设计从哪来，见专题篇 [MLA动机](MLA动机.md)。

# 4. 发展时间线

```text
2017  MHA   ——  Transformer 原始论文（Attention is All You Need）
                 每个头独立 K/V，作为标准结构沿用至今
2019  MQA   ——  Shazeer《Fast Transformer Decoding》
                 极端共享：所有头共用一组 K/V，Decode 显存大幅下降
2023  GQA   ——  Google《GQA: Training Generalized Multi-Query ...
                 Transformer Models from Multi-Head Checkpoints》
                 分组共享，在表达力与显存间取折中，成为新一代基座主流
2024  MLA   ——  DeepSeek-V2
                 低秩压缩 KV，另一条削减 KV Cache 的路线
```

整体趋势：**从「每个头各存一份」走向「尽量少存」，同时尽量不损失表达力。**

- [**MHA**（Multi-Head Attention）](MHA.md)：多头如何切分 H 维、各头独立 Attention 后如何拼接，是其余变体的基准。
- [**MQA**（Multi-Query Attention）](MQA.md)：所有头共用一组 K/V，每个头的 Attention 如何在共享 K/V 下计算。

- [**MLA**（Multi-head Latent Attention）](MLA.md)：不靠共享 K/V，而把 KV 压缩到低维潜变量再还原的另一条路线，重点在压缩-还原的张量流与 KV Cache 削减机理。
- [**MLA 动机**](MLA动机.md)：专题篇——MLA 为什么选择「共享下投影 + 低秩压缩」：从 MQA/GQA 出口共享的困境，到低秩分解思想的合流，以及与原生变换的一致性。

这 4 种覆盖了两条削减 KV Cache 的主流思路：**共享投影**（MQA/GQA）与**低秩压缩**（MLA），MHA 则作为它们共同的对照基准。

并在那之后，顺接 [模型并行](../../模型并行/) 中的 TP——因为 TP 的切分对象正是「头」，而 GQA 的分组结构会让 TP 的切分天然契合。
