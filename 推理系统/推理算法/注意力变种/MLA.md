# MLA：多头潜注意力（Multi-head Latent Attention）

> 本文是「注意力变种」系列的第 4 篇，也是「低秩压缩」路线的代表（DeepSeek-V2 提出）。前三种变体靠**共享 K/V 投影**削减 Cache，MLA 则走另一条路：**把 KV 压缩成一个低维潜变量再还原**。先总览 MLA 对 MHA 四个权重矩阵的改写，再追踪压缩-还原的张量维度转换与 KV Cache 的削减机理。本文是**机制篇**——只讲「怎么运转」；「为什么这么设计」（共享下投影的动机、MQA/GQA 困境与低秩分解的思想谱系）见 [MLA动机](MLA动机.md)。
>
> 关联：[MLA动机](MLA动机.md)（动机篇）、[MHA](MHA.md)、[注意力变种概述](注意力变种概述.md) §3。

---

# 0. 符号约定

```text
S    : 序列长度
H    : 隐藏维度
N    : 头数
d    : 每头维度，d = H / N
d_c  : KV 压缩潜维度（latent dim），d_c ≪ N·d
d_q  : Q 压缩潜维度（q_lora_rank）
d_r  : RoPE 解耦头维（K 的位置部分，小维）
```

MHA 的 KV Cache 是 `[N, S, d]`，总量 `2·N·S·d`。MLA 的目标是：**每层只缓存一个 `[S, d_c]` 的潜变量，且 `d_c ≪ N·d`**，从而把 Cache 压到远小于一组的体量。

---

# 1. MLA 的权重矩阵：MHA 四矩阵被拆成下/上投影

MLA 引发了自注意力权重矩阵的结构性变化：MHA 原本四个独立矩阵 `Wq/Wk/Wv/Wo`，其中 `Wq/Wk/Wv` 各被拆成「**下投影（降维）+ 上投影（升维）**」一对，`Wo` 仍保留为输出投影。先总览每个矩阵在 MLA 下的形态与形状（用 §0 的符号表示）：

| MHA 矩阵 | MLA 下的形态                                                 | 形状                                                                          |
| -------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| `Wq`   | 下`W_dq` + 上 `W_uq`                                     | `W_dq:[H, d_q]`；`W_uq:[d_q, N·d]`                                       |
| `Wk`   | 共享下`W_dkv` + 上 `W_uk`（nope）+ 直连 `W_kr`（rope） | `W_dkv:[H, d_c]`（与 `Wv` 共享）；`W_uk:[d_c, N·d]`；`W_kr:[H, d_r]` |
| `Wv`   | 共享下`W_dkv` + 上 `W_uv`                                | `W_dkv` 同上（与 `Wk` 共享）；`W_uv:[d_c, N·d]`                        |
| `Wo`   | 仍是输出投影                                                 | `Wo:[N·d, H]`                                                              |

结构要点：

- **`Wk` 与 `Wv` 共享下投影 `W_dkv`**——这是 MLA 把 K、V 缓存合一的关键：Cache 里只有一份 `c_KV`，而非 MHA 的两份 K/V。为何共享、思路从哪来，见 [MLA动机](MLA动机.md)。
- **`Wk` 多出一条直连 `W_kr`**，用于 RoPE 解耦的位置部分，不经潜变量、与 `W_dkv` 路径并列。
- **上投影 `W_uk`/`W_uv` 在推理时是否物化**，取决于「权重吸收」，留到 §5 详述；此处只需知道它们存在于权重文件中、是还原 K/V 的计算路径。

下面三节按「压缩 → 还原 → Q 对称处理」的顺序，展开这条降维-升维的张量流。

---

# 2. 压缩：X → 潜变量 c_KV

MLA 先用下投影矩阵 `W_dkv`，把 `X` 从 `H` 维压到 `d_c` 维的潜变量：

```text
W_dkv : [H, d_c]

c_KV = X × W_dkv   →  [S, H] × [H, d_c]  →  [S, d_c]
```

`c_KV` 是后续 K、V 的共同来源——**只有它需要被缓存**。由于 `d_c` 是一个与头数 N 无关的小常数，这一步把「按头存储」彻底改为「按一个低维潜变量存储」。

---

# 3. 还原：c_KV → K / V

推理时，由 `c_KV` 经两个上投影矩阵分别还原出多头 K 与 V：

```text
W_uk : [d_c, N·d]
W_uv : [d_c, N·d]

K_raw = c_KV × W_uk   →  [S, d_c] × [d_c, N·d]  →  [S, N·d]
V_raw = c_KV × W_uv   →  [S, d_c] × [d_c, N·d]  →  [S, N·d]
```

再按 MHA 的方式分头：

```text
K_raw : [S, N·d]  →  reshape (N, d)  →  [S, N, d]  →  K : [N, S, d]
V_raw : [S, N·d]  →  V : [N, S, d]
```

还原出的 K/V 形状与 MHA 完全一致，后续每个头内的 Attention `Q_i×K_i^T → ×V_i` 与 MHA 相同。

---

# 4. Q 的处理（与 K/V 对称的压缩）

为保持对称并控制 Q 侧的计算，MLA 对 Q 也做一次类似的下/上投影：下投影 `W_dq` 把 `X` 压到 `d_q` 维潜变量 `c_Q`，再上投影 `W_uq` 还原回多头 Q（形状见 §1 表）。张量形式与 K/V 的压缩-还原同构，只是 **Q 不参与 Cache**（`c_Q` 每 token 现算现用、不跨 token 留存），此处不展开 Q 的细节，不影响理解 Cache 削减主线。

---

# 5. 关键工程技巧：权重吸收，避免还原

上投影还原（§3）看似在 Decode 时每步都要把 `c_KV` 乘 `W_uk/W_uv` 还原成 `[N, S, d]`，那样 Cache 虽小、计算却没省。MLA 的关键工程技巧是**权重吸收**：

- 由于 Attention 只关心 `Q × K^T` 与 `× V`，可以把上投影矩阵 `W_uk` 吸收进 Q 的投影权重、`W_uv` 吸收进输出投影 `Wo`；
- 吸收后，**推理路径不再显式还原出 K/V**，而是直接用潜变量 `c_KV` 参与计算，把上投影的代价折进 Q/Wo 这一步；
- 因此 Decode 阶段既不需要存完整 K/V，也不需要每步重算上投影。

> 说明：位置编码（RoPE）无法被完全吸收，MLA 采用「RoPE 解耦」——把 K 拆成不带位置的潜变量部分（可吸收）和单独的小维度 RoPE 部分（单独存）。这部分涉及位置编码细节，本文不展开，仅提示它的存在是为了让「吸收」与「位置信息」同时成立。

## 5.1 推理时哪些矩阵真正物化

吸收之后，§1 列出的四组矩阵在推理路径上的落点：

| 矩阵      | 推理物化情况                                   |
| --------- | ---------------------------------------------- |
| `W_dq`  | 物化（产出`c_Q`，不缓存）                    |
| `W_dkv` | 物化且**落 Cache**（产出 `c_KV`）      |
| `W_kr`  | 物化（RoPE 不可吸收，单独存）                  |
| `W_uq`  | 融合`W_uk^T` 后物化                          |
| `W_uk`  | **不物化**，被吸收进 `W_uq`            |
| `W_uv`  | **不物化**，被吸收进 `Wo`              |
| `Wo`    | 物化（融合`W_uv` 后，生效矩阵 `W_uv·Wo`） |

也就是说，`Wk`、`Wv` 作为独立矩阵在推理时已不存在——下投影 `W_dkv` 落 Cache、上投影 `W_uk`/`W_uv` 分别折进 `W_uq`/`Wo`，这正是「拆成下/上投影 + 吸收」带来的彻底改写。真正物化的是：`W_dq`、`W_dkv`（落 Cache）、`W_kr`、融合后的 `W_uq·W_uk^T`、融合后的 `W_uv·Wo`。

---

# 6. KV Cache 形状：压到 d_c

吸收之后，每层真正需要缓存的只有潜变量（外加一个很小的 RoPE 解耦部分）：

```text
c_KV Cache : [S, d_c]          （主部分）
(+ 解耦 RoPE 部分，量级远小于 N·d·S)
```

对比：

```text
MHA : [N, S, d] × 2            总量 2·N·S·d
MQA : [S, d] × 2               总量 2·S·d
GQA : [G, S, d] × 2            总量 2·G·S·d
MLA : [S, d_c] (+ 小量)        总量 ≈ S·d_c
```

当 `d_c < d` 时，MLA 的 Cache 甚至比 MQA 还小，且**不依赖共享 K/V、保留了完整的多头 K/V 还原能力**——这是它与共享投影路线的本质区别。

---

# 7. 小结

```text
权重矩阵（§1）：  Wq→W_dq+W_uq；Wk→W_dkv+W_uk+W_kr；Wv→W_dkv+W_uv；Wo 保留
压缩（§2）：      X:[S,H] × W_dkv:[H,d_c] → c_KV:[S,d_c]        ← 只缓存这个
还原（§3）：      c_KV × W_uk/W_uv → K/V:[N,S,d]                ← 计算路径，不落 Cache
吸收（§5）：      W_uk/W_uv 折进 W_uq/Wo，推理不显式还原 K/V
Cache（§6）：     [S, d_c] (+ 解耦 RoPE 小量)                    ← 远小于 [N,S,d]
```

MLA 的本质：**用「压缩-还原」代替「共享投影」**——共享投影路线（MQA/GQA）是减少 K/V 的份数，MLA 则是减少 K/V 的维度，把每层的 KV Cache 压成一个与头数无关的低维潜变量，同时靠权重吸收让还原几乎零代价。它代表了削减 KV Cache 的另一条主流思路。
