# MLA：多头潜注意力（Multi-head Latent Attention）

> 本文是「注意力变种」系列的第 4 篇，也是「低秩压缩」路线的代表（DeepSeek-V2 提出）。前三种变体靠**共享 K/V 投影**削减 Cache，MLA 则走另一条路：**把 KV 压缩成一个低维潜变量再还原**。重点追踪压缩-还原的张量维度转换与 KV Cache 的削减机理。
>
> 关联：[MHA](MHA.md)、[注意力变种概述](注意力变种概述.md) §3。

---

# 0. 符号约定

```text
S    : 序列长度
H    : 隐藏维度
N    : 头数
d    : 每头维度，d = H / N
d_c  : KV 压缩潜维度（latent dim），d_c ≪ N·d   （DeepSeek-V2 取 512 一类小值）
```

MHA 的 KV Cache 是 `[N, S, d]`，总量 `2·N·S·d`。MLA 的目标是：**每层只缓存一个 `[S, d_c]` 的潜变量，且 `d_c ≪ N·d`**，从而把 Cache 压到远小于一组的体量。

---

# 1. 压缩：X → 潜变量 c_KV

MLA 先用一个下投影矩阵 `W_dkv`，把 `X` 从 `H` 维压到 `d_c` 维的潜变量：

```text
W_dkv : [H, d_c]

c_KV = X × W_dkv   →  [S, H] × [H, d_c]  →  [S, d_c]
```

`c_KV` 是后续 K、V 的共同来源——**只有它需要被缓存**。由于 `d_c` 是一个与头数 N 无关的小常数，这一步把「按头存储」彻底改为「按一个低维潜变量存储」。

---

# 2. 还原：c_KV → K / V

推理时，由 `c_KV` 经两个上投影矩阵分别还原出多头 K 与 V：

```text
W_uk : [d_c, N·d]
W_uv : [d_c, N·d]

K_raw = c_KV × W_uk   →  [S, d_c] × [d_c, N·d]  →  [S, N·d]
V_raw = c_KV × W_uv   →  [S, d_c] × [d_c, N·d]  →  [S, N·d]
```

再按 MHA 的方式分头：

```text
K_raw : [S, N·d]  →  reshape (N, d)  →  [S, N, d]  →  K : [N, S, d]
V_raw : [S, N·d]  →  V : [N, S, d]
```

还原出的 K/V 形状与 MHA 完全一致，后续每个头内的 Attention `Q_i×K_i^T → ×V_i` 与 MHA 相同。

---

# 3. Q 的处理（与 K/V 对称的压缩）

为保持对称并控制 Q 侧的计算，MLA 对 Q 也做一次类似的下/上投影（下投影到 `d_c` 量级再上投影回 `N·d`），张量形式同上，只是 Q 不参与 Cache，此处不展开 Q 的细节，不影响理解 Cache 削减主线。

---

# 4. 关键工程技巧：权重吸收，避免还原

上投影还原（§2）看似在 Decode 时每步都要把 `c_KV` 乘 `W_uk/W_uv` 还原成 `[N, S, d]`，那样 Cache 虽小、计算却没省。MLA 的关键工程技巧是**权重吸收**：

- 由于 Attention 只关心 `Q × K^T` 与 `× V`，可以把上投影矩阵 `W_uk` 吸收进 Q 的投影权重、`W_uv` 吸收进输出投影 `Wo`；
- 吸收后，**推理路径不再显式还原出 K/V**，而是直接用潜变量 `c_KV` 参与计算，把上投影的代价折进 Q/Wo 这一步；
- 因此 Decode 阶段既不需要存完整 K/V，也不需要每步重算上投影。

> 说明：位置编码（RoPE）无法被完全吸收，MLA 采用「RoPE 解耦」——把 K 拆成不带位置的潜变量部分（可吸收）和单独的小维度 RoPE 部分（单独存）。这部分涉及位置编码细节，本文不展开，仅提示它的存在是为了让「吸收」与「位置信息」同时成立。

---

# 5. KV Cache 形状：压到 d_c

吸收之后，每层真正需要缓存的只有潜变量（外加一个很小的 RoPE 解耦部分）：

```text
c_KV Cache : [S, d_c]          （主部分）
(+ 解耦 RoPE 部分，量级远小于 N·d·S)
```

对比：

```text
MHA : [N, S, d] × 2            总量 2·N·S·d
MQA : [S, d] × 2               总量 2·S·d
GQA : [G, S, d] × 2            总量 2·G·S·d
MLA : [S, d_c] (+ 小量)        总量 ≈ S·d_c
```

当 `d_c < d` 时，MLA 的 Cache 甚至比 MQA 还小，且**不依赖共享 K/V、保留了完整的多头 K/V 还原能力**——这是它与共享投影路线的本质区别。

---

# 6. 小结

```text
压缩：  X:[S,H] × W_dkv:[H,d_c] → c_KV:[S,d_c]        ← 只缓存这个
还原：  c_KV × W_uk/W_uv → K/V:[N,S,d]                ← 计算路径，不落 Cache
吸收：  W_uk/W_uv 折进 Q/Wo，推理不显式还原 K/V
Cache： [S, d_c] (+ 解耦 RoPE 小量)                    ← 远小于 [N,S,d]
```

MLA 的本质：**用「压缩-还原」代替「共享投影」**——共享投影路线（MQA/GQA）是减少 K/V 的份数，MLA 则是减少 K/V 的维度，把每层的 KV Cache 压成一个与头数无关的低维潜变量，同时靠权重吸收让还原几乎零代价。它代表了削减 KV Cache 的另一条主流思路。
