# RoPE：旋转位置编码

> 本文专注讲清 RoPE 本身——它的概念、动机、流程，以及在普通 Self-Attention 和 MHA 中的落地。
>
> 关联：[自回归生成](<../../0-Transformer%20自回归生成的最小闭环.md>) §3 的 Q/K/V。

---

# 0. 符号约定

```text
S    : 序列长度
d    : 每头维度（head_dim）
θ_i  : 第 i 个频率对的角度系数，i = 0..d/2-1
m, n : token 位置
```

RoPE 只作用于 **Q 和 K**，不碰 V。

---

# 1. 动机：自注意力为何需要位置编码，为何选旋转

**问题**：原始 Self-Attention 的 `Q × K^T` 对 token 顺序不敏感——交换两个 token 的位置，它们之间的分数不变（运算对排列等价）。于是「猫坐垫子」和「垫子坐猫」在无位置信息时看起来一样。要让模型区分语序、距离，必须把位置信息注入 Q/K。

**两条路线**：

- **绝对位置**：给每个位置学一个向量加到 token 上。简单，但相对距离要模型自己学，泛化到长序列差。
- **相对位置**：让 `Q_m · K_n` 直接依赖相对距离 `n-m`。这正是我们想要的——注意力本质关心「两个 token 离多远」，而非「各自在第几位」。

**为什么用旋转**：在二维平面里，对位置 `m` 的向量旋转角度 `m·θ`、位置 `n` 的向量旋转 `n·θ`，两者点积 `(R_m q)·(R_n k) = q·R_{n-m}·k` 只含相对角度 `(n-m)·θ`——**相对位置天然从旋转的合成里掉出来，不用显式算距离**。把 `d` 维切成多个二维对、每对配不同频率 `θ_i`，就能同时表达多种距离尺度。这就是 RoPE 的全部动机。

---

# 2. 概念与流程：普通 Self-Attention 的 RoPE

单头，`Q, K : [S, d]`（以 `d=4` 为例）。流程三步：

**① 切对**：把 `d` 维切成 `d/2` 个二维对，每对配频率 `θ_i`：

```text
d=4 → 2 个对：pair0 = (dim0, dim1)，pair1 = (dim2, dim3)
每个对 i 配频率 θ_i
```

> **限定条件**：切对要求 `d` 为偶数，所以 RoPE 的约束落在**头维 `d`** 上，不在 `H` 本身——单头 SA 要求 `H` 偶数，MHA 要求 `H/N` 偶数。注意力运算本身不要求偶数，这是 RoPE 配对带来的；工程上 `d` 还会取 64/128 这类 2 的高次幂倍数以适配 tensor core。

**② 旋转**：对位置 `m` 的 token，把它 Q 的第 `i` 个对在二维平面里旋转角度 `m·θ_i`：

```text
pair_i  ←  R(m·θ_i) · pair_i
R(φ) = [ cos φ, -sin φ ]
       [ sin φ,  cos φ ]
```

K 同理，按各自位置 `n` 旋转。**整步是分块旋转，作用在 `d` 维内部，原地不增维**：

```text
Q : [S, d]  →  按位置原地旋转  →  Q' : [S, d]     # 形状不变
K : [S, d]  →  按位置原地旋转  →  K' : [S, d]
```

> **旋转角度的取值**：角度 = 位置 × 频率，即 `φ_i(m) = m·θ_i`；不同 pair 配不同频率（几何序列 `θ_i = base^{-2i/d}`），同一 pair 的 Q/K 共用同一个 `θ_i`。**这是 RoPE 变换的关键与核心，单独展开见 §3。**

**③ 算分数**：照常 `Score = Q' × K'^T → [S, S]`，V 不动。

**相对位置为何成立**：旋转可合成——

```text
(Q'_m)·(K'_n) = (R_m·q_m)·(R_n·k_n) = q_m · R_{n-m} · k_n
```

分数只依赖 `n-m`，与绝对位置无关。这就是 RoPE 流程的落点：**投影出 Q/K → 原地旋转 → 算分数**，三步走完，张量形状全程 `[S, d]` 不变。

---

# 3. 旋转角度的取值：RoPE 的关键与核心

§2 的 ② 只说「转角度 `m·θ_i`」，没说这个角度怎么定。它其实是整个 RoPE 最核心的设计，一句话：**角度 = 位置 × 频率**。

## 3.1 两层拆解：频率固定，角度随位置累积

假设Q和K为[n, h]的张量，其中n为序列长度，h为隐藏维度。隐藏维度h是固定，rope的核心为让Transformer 原始 Attention关注token的位置，所以rope旋转角度就需要引入token位置进行计算，具体方法见下文

把序列想成传送带，token 一个个往前走。**每前进一个位置，第 i 个 pair 固定多转 `θ_i`**——`θ_i` 是模型常量（由hidden_size确定），管的是「节奏」；**实际旋转角 = 该 token 的位置 m × 该 pair 的频率 θ_i**，位置走多远、累计转多少，管的是「进度」。仍看 `d=4` 里的 pair1（`θ_1=0.01`）：

```text
位置 m:    0       100        314          628
旋转角:    0       1 弧度     π（半圈）     2π（整圈）
```

于是有两个「不同」：同一个 token 在不同 pair 上转角不同（频率不同）；同一个 pair 在不同位置的 token 上转角不同（位置不同）。**不变的是频率，变的是位置。**

## 3.2 频率 θ_i 由三个因素决定

批注-zyh：先强调θ_i的取值范围，本质上频率 θ_i是由hidden_size和base决定的，其中的3因素只是特定计算参数，请你修改一下，不要让读者混淆

`θ_i = base^{-2i/d}`，三个输入：

- **`i`（pair 序号）**：`0..d/2-1`，越靠后的 pair 频率越小、转得越慢；
- **`d`（头维度）**：模型结构定死（如 128），决定频率刻度的总数；
- **`base`（衰减底数）**：超参，默认 10000（配置项 `rope_theta`），决定频率递减多快。

以 `d=4, base=10000` 代入：

```text
pair0: θ_0 = 10000^(-0/4) = 1      # 每步转 1 弧度，波长 2π ≈ 6 token —— 高频管短程
pair1: θ_1 = 10000^(-2/4) = 0.01   # 每步转 0.01 弧度，波长 ≈ 628 token —— 低频管长程
```

频率按 `1, 0.01, 10^-4, ...` **等比递减（几何序列）**；`d=128` 时共 64 个频率，从 1 一路递减到 `10^-4`。这相当于一把同时有毫米刻度和米刻度的尺子：高频 pair 的点积贡献随相对距离**振荡得快**，对「差 1 还是差 3 个 token」敏感；低频 pair **振荡得慢**，长距离上仍能区分「差 100 还是差 200」。

最低频 pair 的波长约为 `2π·base`（base=10000 时约 6 万 token）。序列一旦比这更长，最慢的「指针」也转完一圈，位置信息开始重合——所以长上下文模型把 base 调大（500000、8e6 等），让最慢的频率更慢、在几十万 token 跨度内还没走完一圈。这就是「调大 `base` 扩展长上下文」的机理。

## 3.3 Q/K 必须同频：绝对位置如何消掉

Q 在位置 `m` 转 `m·θ_i`，K 在位置 `n` 转 `n·θ_i`——**同一个 pair 共用同一个 `θ_i`**，点积时两个旋转合成：

```text
R(m·θ)ᵀ · R(n·θ) = R((n-m)·θ)
```

两个角相减，绝对位置恰好消掉，只剩 `(n-m)·θ`。若 Q/K 用不同频率，这一相减不成立，绝对位置会泄漏进分数。所以「每个 token 按自己的绝对位置旋转」只是**手段**，「注意力感知相对距离」才是**目的**。

# 4. MHA 下的 RoPE

MHA 把 `d` 拆成 N 个头，`Q, K : [N, S, d]`。RoPE 在**每个头的 `d` 维上**做和 §2 一模一样的事：

```text
Q : [N, S, d]  →  每头按位置原地旋转  →  Q' : [N, S, d]    # d 不变
K : [N, S, d]  →  同理               →  K' : [N, S, d]
```

`θ_i` 各头通常相同。然后每头 `Q'_i × K'_i^T → [S, S]`，与无 RoPE 时完全一致，只是 Q/K 现在带位置信息。

**整个 RoPE 流程对 MHA 张量形状零影响，故RoPE对MHA的计算流程没有任何影响**：`[N, S, d]` 进、`[N, S, d]` 出，只是算分数前对 Q/K 各原地转一下。

---

# 5. 小结

```text
动机：  Self-Attention 对顺序不敏感 → 需注入位置
        旋转使 Q_m·K_n 天然依赖相对位置 n-m
概念：  对 Q/K 做「分块二维旋转」，原地、不增维
角度：  φ_i(m) = m·θ_i —— 频率 θ_i（i/d/base 定，几何递减）是常量，
        位置 m 是进度；Q/K 同频 → 绝对位置在点积中相消
流程：  投影出 Q/K → 按位置原地旋转 → 算分数
        普通 SA：[S,d] 不变；MHA：[N,S,d] 不变
```

一句话：**RoPE 是「算分数前对 Q/K 按 token 位置做一次原地分块旋转」，不改变任何张量维度，靠旋转的合成性让注意力分数天然带上相对位置信息。**
