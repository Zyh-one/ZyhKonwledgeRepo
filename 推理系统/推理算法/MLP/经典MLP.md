# 经典 MLP：升维 → 激活 → 降维

> 本文是「MLP」系列的第 1 篇，详细追踪最经典形态 MLP 的张量维度转换。它把 [自回归生成](<../0-Transformer%20自回归生成的最小闭环.md>) §4 中那段「升维→激活→降维」的骨架展开成完整张量流，并补上该节末尾批注希望展开的「非线性激活」一节。
>
> 关联：[自回归生成](<../0-Transformer%20自回归生成的最小闭环.md>) §4「MLP 后仍然得到 `[S,H]`」；[注意力变种概述](../注意力变种/注意力变种概述.md) §2「什么是头」中关于 H 维的口径。后续 SwiGLU / GeGLU 等门控变体将另开文档。

---

# 0. 符号约定

```text
S        : 序列长度（Prefill 为 Prompt 长度，Decode 时为 KV Cache 长度）
H        : 隐藏维度（hidden_size），即每个 token 的 Hidden State 向量长度
d_ff     : MLP 中间维度（feed-forward dimension），经典取 d_ff = 4H
W_up     : 升维权重矩阵，形状 [H, d_ff] = [H, 4H]
W_down   : 降维权重矩阵，形状 [d_ff, H] = [4H, H]
σ        : 非线性激活函数（本文以 GELU 为例）
```

本文沿用自回归生成的张量主线：MLP 接在 Self-Attention 之后，输入输出维度恒为 `[S, H]`，主流程 `升维 → 激活 → 降维` 三步不变。

---

# 1. MLP 在 Transformer Layer 中的位置

回顾 [自回归生成](<../0-Transformer%20自回归生成的最小闭环.md>) §3 的单层结构，一层 Transformer 由 Self-Attention 与 MLP 两个子模块组成，并配合残差连接（Residual）与归一化（Norm）：

```text
X : [S, H]
   ↓
Self-Attention        （在 H 维的若干子空间里融合 token 间信息）
   ↓
Residual / Norm       （x + Attn(x)，维度仍 [S, H]）
   ↓
MLP                    ← 本文展开这一段
   ↓
Residual              （维度仍 [S, H]）
   ↓
Y : [S, H]
```

也就是说，MLP 拿到的输入是 Attention 处理过、并经残差/Norm 后的 `[S, H]` 张量。**与 Self-Attention 的职责分工**可以这样理解：Attention 负责「token 与 token 之间」的信息融合（横向，跨位置），MLP 负责「单个 token 内部」各维度特征的非线性变换（纵向，跨维度）。两者交替堆叠，才让模型既能跨位置聚合上下文，又能在每个位置上做高维特征的非线性重组。

记 MLP 的输入为 `Z : [S, H]`（即上图 Attention+Residual 的输出），下面进入 MLP 内部。

---

# 2. 张量变换三步

## 2.1 升维：H → 4H

第一步用升维权重 `W_up` 把每个 token 的 Hidden State 从 `H` 维投影到更大的 `d_ff = 4H` 维：

```text
U = Z × W_up   →   [S, H] × [H, 4H]   →   [S, 4H]
```

这里 `W_up : [H, 4H]` 是模型在预训练中学习得到的权重，与 `Wq/Wk/Wv` 同属结构参数（固定不变）。从「水流-河道」的类比看，它是 MLP 这一段的「河道」：水流（`Z`）被它塑形、拓宽到 4H 维。

升维后的 `U : [S, 4H]` 中，每个 token 由一个 `4H` 维向量表示。为什么先放大？因为非线性激活在高维空间里更容易把特征「拉开」到可线性分离的形态，再投回低维——这一点在第 4 节展开。

## 2.2 非线性激活：逐元素、不改维度

升维后紧接着施加非线性激活函数 `σ`：

```text
A = σ(U)   →   [S, 4H]   →   [S, 4H]
```

**这是 MLP 唯一引入非线性的环节。** 关键的张量性质是：

- **逐元素（element-wise）**：激活函数作用在 `U` 的每一个标量分量上，`A[s, j] = σ(U[s, j])`，分量之间互不影响；
- **不改变张量形状**：输入 `[S, 4H]`，输出仍 `[S, 4H]`，没有任何矩阵乘法、没有维度变化。

这一点正是 zyh 在自回归生成 §4 末尾批注想要强调的——**非线性激活本质上也是从 token 的 hidden 维度出发的：它对 `[S, 4H]` 张量最后一维（hidden 维）的每一个分量独立施加非线性变换**。可以按行拆解理解：

```text
U : [S, 4H]  =  [u_1, u_2, ..., u_S]      每个 u_i 是 4H 维向量
        ↓ σ 逐元素作用
A : [S, 4H]  =  [a_1, a_2, ..., a_S]      每个 a_i = σ(u_i)，仍是 4H 维
```

对单个 token 的 `u_i`（一个 `4H` 维向量）而言，激活函数就是对其 4H 个分量各自做一次 `σ(·)`，向量长度不变、位置间不混合。

**为什么必须非线性？** 若去掉激活函数，MLP 退化为 `Z × W_up × W_down`，两个线性矩阵相乘仍是线性矩阵 `W' : [H, H]`，等价于一次普通线性投影——无论堆叠多少层，整体都还是线性的，模型表达力坍缩，无法拟合非线性关系。激活函数的存在让升维后的 4H 维空间被「非线性地裁剪」一遍，再降维回来，才能表达复杂的非线性特征变换。

### 激活函数选型：以 GELU 为例

本文以 **GELU**（Gaussian Error Linear Unit）为经典代表，它是原始 Transformer 论文 *Attention is All You Need* 中 FFN 使用的激活函数。GELU 的核心思想是「按输入自身的值做概率门控」——输入越大越接近保留、越小越接近置零，过渡平滑：

```text
GELU(x) = x · Φ(x)        Φ(x) 为标准正态分布的累积分布函数
        ≈ 0.5x [ 1 + tanh(√(2/π) (x + 0.044715 x³)) ]   （常用 tanh 近似）
```

它的张量行为与 **ReLU**（最早期、最基础的激活函数）在「逐元素、保维度」这一层完全等价，区别只在逐元素施加的函数曲线不同：

| 激活函数 | 公式 | 张量作用 | 出处 |
| --- | --- | --- | --- |
| **ReLU** | `max(0, x)` | 逐元素，负值置零、正值不变，保 `[S,4H]` | 早期 CNN / 通用激活 |
| **GELU** | `x·Φ(x)` | 逐元素，平滑门控，保 `[S,4H]` | 原始 Transformer |

二者都不会改变张量形状，差异只在「负值附近怎么裁」：ReLU 硬截断为 0，GELU 平滑过渡。后续门控变体（SwiGLU / GeGLU）会引入第二个升维分支做门控，张量流不再是单纯的逐元素激活，那是另一条路线，本文不展开。

## 2.3 降维：4H → H

激活后用降维权重 `W_down` 把 `4H` 维投影回 `H` 维：

```text
Y = A × W_down   →   [S, 4H] × [4H, H]   →   [S, H]
```

`W_down : [4H, H]` 同为结构参数。至此 MLP 输出回到 `[S, H]`，与输入维度一致，可以继续做残差连接 `Z + MLP(Z)` 并进入下一层。

---

# 3. 整体张量流

把三步串起来：

```text
Z : [S, H]
  ↓ × W_up   [H, 4H]
U : [S, 4H]
  ↓ σ（GELU，逐元素）
A : [S, 4H]
  ↓ × W_down [4H, H]
Y : [S, H]
```

输入输出恒为 `[S, H]`，中间在 `[S, 4H]` 上做非线性变换——这就是经典 MLP 的全部张量变换。

对比 Self-Attention：Attention 在 `[S, H]` 内部通过 `Q×K^T→Softmax→×V` 跨位置混合信息，形状在 `[S,H]` 与 `[S,S]` 之间往返；MLP 则在 `[S,H]` 与 `[S,4H]` 之间往返，做的是「升维—非线性—降维」的跨维度变换，全程不出现 `[S,S]`，即 MLP 不在 token 之间混合信息（每个 token 独立过 MLP）。

---

# 4. 为什么升维到 4H

中间维度取 `d_ff = 4H` 是经典 Transformer 的常见超参（GPT、BERT 等均沿用）。其动机有二：

1. **扩大表达容量**：把 `H` 维投到 `4H` 维，给非线性激活一个更宽的空间去「拉开」特征。很多在 `H` 维下线性不可分的特征关系，在 `4H` 维的高维空间里更可能被一个超平面分开；再经激活的非线性裁剪、降维投回，等价于在该 token 上做了一次高维空间的非线性特征重组。
2. **参数与计算的平衡**：升维越宽表达力越强，但 `W_up` 与 `W_down` 的参数量 `H·d_ff + d_ff·H = 2·H·d_ff` 随 `d_ff` 线性增长。`4H` 是经验上表达力与开销的折中点；现代门控变体（如 SwiGLU）为补偿门控引入的额外分支，常把比例调小到约 `8H/3`，那是后话。

值得注意：**升维与降维本身是线性的**，非线性完全来自中间的激活。所以「4H 维空间」发挥作用的前提是激活函数夹在两次线性投影之间——先升到高维、做非线性裁剪、再降回去，三者缺一不可。

---

# 5. 小结

```text
MLP 输入 Z : [S, H]
  × W_up   [H, 4H]      升维
  → U : [S, 4H]
  σ(·) 逐元素           非线性激活（GELU），不改形状
  → A : [S, 4H]
  × W_down [4H, H]      降维
  → Y : [S, H]
MLP 输出 Y : [S, H]
```

经典 MLP 的本质：**两次线性投影（升维 / 降维）之间夹一个逐元素的非线性激活，输入输出维度恒为 `[S, H]`，中间在 `[S, 4H]` 上做非线性特征重组。** 它与 Self-Attention 正交——Attention 跨位置混合，MLP 跨维度变换。

后续将展开的门控变体（SwiGLU / GeGLU）改的是「激活这一步」：不再是对单个 `[S,4H]` 逐元素施加 `σ`，而是再升维出一份门控分支、按元素相乘，张量流随之变化，但「升维→非线性→降维、输入输出 `[S,H]`」的骨架不变。
