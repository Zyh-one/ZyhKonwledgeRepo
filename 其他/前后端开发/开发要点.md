* Go 优雅关闭；信号或通道；

  ```
  操作系统发出 SIGINT/SIGTERM
            ↓
  shutdownSignal.Done() 被关闭
            ↓
  后台 goroutine 被唤醒
            ↓
  给服务最多 5 秒处理已有请求
            ↓
  server.Shutdown(...)
            ↓
  ListenAndServe() 返回 http.ErrServerClosed
            ↓
  main 函数正常退出
  ```

* 前端对象分层（API层和业务层）：前端需要接受来自后端的数据，对于一个Resource，后端和前端各自的定义存在区别，所以前端需要将后端定义的Resource结构（API层）转换为自己需要使用的Resource结构（业务层）
  * API 层的类型负责“后端给我什么”，业务层的类型负责“前端想怎么用”。
