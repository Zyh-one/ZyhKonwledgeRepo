# TypeScript 回调函数基本用法

本文只介绍 TypeScript 中回调函数的基本写法。回调函数的设计思想见 [回调函数的编程思想](../../编程思想/回调函数.md)。

## 1. 声明并传入回调函数

```ts
function process(callback: (value: number) => void): void {
  const result = 10;
  callback(result);
}

process((value) => {
  console.log(value);
});
```

- `callback` 是 `process` 的形参。
- `(value: number) => void` 是回调的函数类型。
- `(value) => { ... }` 是传给 `process` 的具体函数值。
- `callback(result)` 调用回调，`result` 的值会传给 `value`。

## 2. `=>` 的两种用途

### 2.1 函数类型

```ts
(x: number, y: number) => number
```

这是类型，表示函数接收两个 `number` 并返回一个 `number`；它不包含可执行逻辑。

```ts
function calculate(
  a: number,
  b: number,
  operation: (x: number, y: number) => number,
): number {
  return operation(a, b);
}
```

### 2.2 箭头函数表达式

```ts
calculate(10, 5, (x, y) => x + y);
```

`(x, y) => x + y` 会创建真正的函数值，并作为 `operation` 的实参。

也可以先保存函数再传入：

```ts
const add: (x: number, y: number) => number = (x, y) => x + y;

calculate(10, 5, add);
```

## 3. 箭头函数的返回值

表达式函数体会自动返回结果：

```ts
const add = (x: number, y: number): number => x + y;
```

使用代码块时需要显式写 `return`：

```ts
const add = (x: number, y: number): number => {
  return x + y;
};
```

下面的函数不会返回相加结果：

```ts
const add = (x: number, y: number) => {
  x + y;
};
```

## 4. 上下文类型推导

如果接收位置已规定函数类型，TypeScript 可以推导箭头函数的参数类型：

```ts
const add: (x: number, y: number) => number = (x, y) => x + y;
```

这里 `x` 和 `y` 都被推导为 `number`。参数不是没有类型，而是类型由上下文提供。

数组方法也会提供上下文类型：

```ts
const numbers = [1, 2, 3];

numbers.map((value) => value * 2);
```

由于 `numbers` 是 `number[]`，`value` 会被推导为 `number`。

没有上下文时，应显式标注参数类型：

```ts
const add = (x: number, y: number): number => x + y;
```

或者先声明整体函数类型：

```ts
type Calculator = (x: number, y: number) => number;

const add: Calculator = (x, y) => x + y;
```

## 5. 回调参数的来源

```ts
const fruits = ['苹果', '香蕉', '橙子'];

fruits.forEach((fruit, index) => {
  console.log(index, fruit);
});
```

- `fruit` 和 `index` 是回调的形参，参数名可以自定义。
- 参数值由 `forEach` 内部调用回调时传入。
- 参数的位置、含义和类型由 `forEach` 的方法签名规定。

可以把它简化理解为：

```ts
for (let index = 0; index < fruits.length; index++) {
  callback(fruits[index], index, fruits);
}
```

不使用靠前的参数时，常用下划线表示它已被接收但未使用：

```ts
fruits.forEach((_fruit, index) => {
  console.log(index);
});
```

## 6. 解构回调参数

```ts
interface User {
  id: number;
  name: string;
}

const users: User[] = [
  { id: 1, name: '小王' },
  { id: 2, name: '小李' },
];

users.forEach(({ id, name }) => {
  console.log(id, name);
});
```

`forEach` 每次传入一个 `User` 对象，`{ id, name }` 会把该对象解构为两个局部变量。它等价于：

```ts
users.forEach((user) => {
  const { id, name } = user;
  console.log(id, name);
});
```

## 7. 常见用法

### 7.1 数组方法

```ts
const doubled = [1, 2, 3].map((value) => value * 2);
const even = [1, 2, 3].filter((value) => value % 2 === 0);
```

### 7.2 定时器

```ts
setTimeout(() => {
  console.log('稍后执行');
}, 1000);
```

### 7.3 RxJS

```ts
of('Angular', 'RxJS').subscribe({
  next: (value) => {
    console.log('收到:', value);
  },
  complete: () => {
    console.log('完成');
  },
});
```

`next` 会接收数据，`complete` 不接收参数，因此写为 `() => { ... }`。

## 8. 使用命名函数作为回调

回调不必在调用处临时定义，也可以直接传入已定义的函数：

```ts
function double(value: number): number {
  return value * 2;
}

numbers.map(double);
```
