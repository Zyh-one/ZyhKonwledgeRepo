# 个人知识库

本仓库用于沉淀学习、工作与科研过程中积累的知识，当前以 AI Infra 为主要方向。内容按照完成度和用途划分：成熟内容进入对应的专题目录，阶段性材料进入调研或学术目录，未经整理的日常记录则暂存于草稿区。

## 目录结构

### `集群调度/`

记录集群资源管理与任务调度方向的知识，包括但不限于调度策略、资源分配、任务编排、异构算力管理以及相关系统的设计与实现。

该目录中的内容应整理为结构完整、表述清晰的博客文章，原则上可以直接迁移到博客网站发布。

### `推理系统/`

记录大模型及其他深度学习模型的推理系统知识，包括推理框架、模型并行、CUDA 算子、性能优化和工程实现细节等。

该目录属于 AI Infra 核心内容，文章应经过系统整理，并达到可直接发布的标准。

### `训练系统/`

记录模型训练系统相关内容，包括分布式训练、并行策略、训练框架、通信与计算优化、资源利用及容错等方向。

该目录属于 AI Infra 核心内容，文章应具有相对完整的背景、原理、实现与总结，可直接作为博客文章使用。

### `学术/`

存放学术研究相关内容，包括个人课题记录、研究方法、论文清单、论文解读以及实验分析等。

这里的内容可以服务于个人科研工作，不强制要求达到博客文章的发布标准，但应尽量保证论述严谨、来源明确。

### `随想录/`

记录学习和科研过程中产生的问题、思考与判断，也可包含对技术发展和未来趋势的预测。

该目录强调个人思考和问题意识，允许内容具有探索性，不要求形成完整的技术文章。

### `调研/`

存放 AI Infra 方向的专题调研，包括技术路线梳理、方案对比、系统现状、适用场景、限制与待验证结论等。

调研内容通常是阶段性的，可在材料成熟后进一步整理为专题博客、学术文章或项目方案。

### `Draft/`

存放尚未整理完成的草稿和日常记录。工作与学习过程中按日期随手记录的内容统一放入 `Draft/日志/`，建议使用 `YYYY-MM-DD.md` 命名。

该目录需要定期清理：成熟内容应迁移到对应专题目录，仍需补充的内容继续保留，无后续价值、重复或过时的内容可以删除。

### `source/`

统一存放 Markdown 文档引用的本地图片等资源。图片按照其所属 Markdown 文件的路径分类组织，并由仓库中的图片整理工具定期检查和规范。

一般情况下，不直接在此目录中编写知识内容。

## 内容流转

日常工作和学习中的零散内容，先记录在 `Draft/日志/`；定期回顾后，再根据内容的主题、用途和成熟度迁移至相应目录：

- 可发布的 AI Infra 技术文章进入 `集群调度/`、`推理系统/` 或 `训练系统/`。
- 课题研究、论文解读和实验分析进入 `学术/`。
- 个人问题、观点和趋势判断进入 `随想录/`。
- 阶段性技术调查与方案比较进入 `调研/`。
- 尚未成熟的内容继续保留在 `Draft/`，无保留价值的内容及时清理。

通过这一方式，使知识从原始记录逐步转化为结构清晰、便于检索和复用的长期内容。
