- HTML：

    - 类比Markdown格式

    - 通常，HTML是分块的（Head和Body）

    - 树形结构；双标签节点\<xxx\> \</xxx\>和单标签节点\<yyy\>

        - DOM树

- DOM树：文档对象模型

    - HTML网页运行时状态；类比yaml和k8s中的运行时组件

    - 两者的结构是一样的，HTML网页 \-\-\- 浏览器解析 \-\-\-\> DOM树

    - JavaScript也是通过DOM树来修改或增加网页中的相关内容

- HTML标签：（不用全部掌握，在AI辅助的场景下，实际工作不需要深究HTML的标签）

    - \<div\>：容器

    - 标题标签 `<h1>` \~ `<h6>`

    - `<p>`：文本段落

    - `<span>`：行内小区域；和`<div>`类似

    - `<button>`：按钮

    - `<img>`：图片

    - `<a>`：链接

- HTML属性：描述标签；

    ```HTML
    <div
    id="app"
    class="container">
    </div>
    ```

    - 作用：

        - 供“浏览器”直接消费；比如src，href

        - 供“CSS”消费；比如class，id

        - 供“JavaScript”消费；

            - JS 会通过 `document.getElementById('reset')` 找到 ID 为 reset 的按钮，然后进行相关操作

- CSS：控制HTML结构的页面布局；1\. 选中元素，2\. 控制元素如何显示

    - 基本工作方式：

    ```HTML
    选择器 {
        属性: 值;
    }
    ```

    - 选择器：通过指定Class选择HTML中的相关模块

- 选择器：从 DOM 树中找到一组 HTML 元素，然后把样式应用到这些元素上

    - 标签选择器

    - 类选择器 `.`

    - ID 选择器 `#`

    - 后代选择器：空格

    - \.\.\.

    - 总之：最终目标都是匹配 DOM 树中的一个元素，或者一组元素。
