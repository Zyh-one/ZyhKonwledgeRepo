**通过Svc查找对应的Pod**

第一种：从svc内部yaml配置提取target标签，然后再匹配指定pod

Service通过`spec.selector` 去匹配底层 Pod 的，最直接的命令：

```
kubectl get pods -n envoy-gateway-system \
  -l 'app.kubernetes.io/component=proxy,app.kubernetes.io/managed-by=envoy-gateway,app.kubernetes.io/name=envoy,gateway.envoyproxy.io/owning-gateway-name=aibrix-eg,gateway.envoyproxy.io/owning-gateway-namespace=aibrix-system' \
  -o wide
```

第二种：从Svc对应的endpoints入手

```
kubectl get endpoints <svc-name> -n <namespace>
```

获取后端服务对应的IP，然后用Pod IP反查

```
kubectl get pods -n devplatform -o wide | grep 10.9.41.250
```

**k8s  get pod展示Pod的标签**

```
kubectl get pods -A --show-labels
```

**查看Pod的创建路径：deploy --> replicaset --> pod等等**

执行

```
kubectl -n kube-system get pod nginx-proxy-cam-train-013 \
  -o jsonpath='{.metadata.ownerReferences}'
```

在pod的yaml中执行搜索“ownerReference”，适用于replicas，pod
