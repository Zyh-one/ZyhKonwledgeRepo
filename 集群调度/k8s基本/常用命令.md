

**通过Svc查找对应的Pod**

Service通过`spec.selector` 去匹配底层 Pod 的，最直接的命令：

```
kubectl get pods -n envoy-gateway-system \
  -l 'app.kubernetes.io/component=proxy,app.kubernetes.io/managed-by=envoy-gateway,app.kubernetes.io/name=envoy,gateway.envoyproxy.io/owning-gateway-name=aibrix-eg,gateway.envoyproxy.io/owning-gateway-namespace=aibrix-system' \
  -o wide
```


**k8s  get pod展示Pod的标签**

```
kubectl get pods -A --show-labels
```
