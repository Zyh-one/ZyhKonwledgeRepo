# 部署变体与安装流程

[返回总览](./README.md)

## `overlays/`

Overlay 在 Base 配置上表达环境差异，应尽量只保存差异，不复制完整 Base YAML。

| Overlay | 作用 |
| --- | --- |
| `dev/` | 替换 Manager、Gateway Plugin、GPU Optimizer 的开发环境配置 |
| `release/` | 使用稳定版本镜像，增加 PDB 和生产向 Patch |
| `vke/` | 修改 VKE 平台依赖、镜像和 Envoy 配置 |
| `vke-dev/` | VKE 开发环境配置 |
| `vke-ipv6/` | IPv6 网络环境配置 |

## `standalone/`

支持只部署某一类 Controller：

- `autoscaler-controller/`；
- `model-adapter-controller/`；
- `stormservice-controller/`；
- `distributed-inference-controller/`；
- `kv-cache-controller/`。

每个目录只组合相关 CRD、RBAC、Manager 和专用 Patch，用于缩小安装范围、独立扩缩容和隔离故障。

## `test/`

以 `default/` 为基础追加测试专用 Patch，例如 Gateway VTC 环境变量。它用于本地 Kind 和 CI，不包含 Mock vLLM 本身；Mock 后端位于 `development/app/config/mock/`。

## `samples/`

包含 PodAutoscaler、ModelAdapter、KVCache、StormService、RoleSet 和 Ray 相关 CR 的示例实例。

```text
config/crd
    → 定义资源类型

config/samples
    → 展示如何创建资源实例
```

Samples 不是 AIBrix 控制面的固定组件，部分示例依赖真实模型、存储或特定集群能力。

## `experimentals/`

保存实验性能力的部署配置，例如 GPU Optimizer 与 Gateway Plugin 的实验性集成，不应默认视为稳定生产接口。

## 安装顺序

```text
1. make install
   └── kubectl apply -k config/dependency --server-side
       ├── 安装 Envoy Gateway
       └── 安装 KubeRay CRD

2. make deploy
   └── kustomize build config/default | kubectl apply -f -
       ├── Namespace、AIBrix CRD 和 RBAC
       ├── Controller Manager
       ├── Gateway Plugin 和 Envoy Gateway API 资源
       ├── Metadata Service、Redis、GPU Optimizer
       └── KubeRay Operator、Webhook 和 TLS Secret

3. 部署模型工作负载
   ├── development/app/config/mock（本地 Mock）
   ├── samples/（场景示例）
   └── 真实 vLLM/SGLang 部署
```

## 部署后的关联关系

```text
AIBrix CRD
    → Controller Manager
    → 创建和维护推理工作负载

Gateway / EnvoyProxy
    → Envoy Gateway Controller
    → 创建 Envoy Proxy

EnvoyExtensionPolicy
    → Gateway Plugin
    → Router 选择模型 Pod

EnvoyPatchPolicy
    → 读取 target-pod
    → Envoy 将请求转发到目标模型 Pod
```

## 归纳

`config/` 可以理解为三层：

1. **基础能力模块**：`crd`、`rbac`、`manager`、`gateway`、`metadata`、`webhook` 等。
2. **部署组合模块**：`default`、`standalone`，决定一次部署包含哪些能力。
3. **环境定制模块**：`overlays`、`test`、`release`，决定镜像、参数、资源和网络配置。
