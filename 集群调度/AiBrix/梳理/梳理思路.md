开始进入AiBrix相关组件的梳理，两条链路：

* 控制链路：CR ----> Controller -----> k8s资源
* 请求链路：用户请求 ----->  GateWay -----> 推理引擎

分别对应两条核心工作流

控制工作流（CRD+Controller）

```
用户提交 YAML/CR
        ↓
API Server 调用 Webhook 校验
        ↓
API Server 保存资源
        ↓
Controller Watch 到事件
        ↓
Controller 执行 Reconcile
        ↓
创建 Deployment、Pod、Service、RoleSet 等
        ↓
更新 CR Status
```

推理请求工作流（Gateway + 数据面）

```
用户发送 OpenAI 兼容请求
        ↓
Envoy Gateway
        ↓
AIBrix Gateway Plugin
        ↓
选择可用且合适的推理实例
        ↓
vLLM/SGLang 执行推理
        ↓
可能读写 AIBrix KV Cache
        ↓
返回生成结果
```


当前梳理过程只需要看cmd/ + api/ + pkg/就够了，后面再补充python/（推理运行时与KV Cache数据面）
