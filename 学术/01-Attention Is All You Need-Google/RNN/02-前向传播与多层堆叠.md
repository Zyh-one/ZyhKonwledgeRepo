# RNN 前向传播与多层堆叠

本文拆解单层 RNN 的一个时间步在算什么、各权重矩阵是什么形状，以及权重共享与串行依赖的来源；随后把视角拉到多层，说明 RNN 的「横向时间、纵向层」二维结构，并附一段可直接运行的 PyTorch 最小示例。

## 3. 单层 RNN 的前向传播与张量维度

对单个时间步：

$$
\begin{aligned}
x_t&\in\mathbb{R}^E,\quad h_{t-1}\in\mathbb{R}^H\\
W_x&\in\mathbb{R}^{H\times E},\quad W_h\in\mathbb{R}^{H\times H}\\
z_t&=W_x x_t+W_h h_{t-1}+b\in\mathbb{R}^H\\
h_t&=\tanh(z_t)\in\mathbb{R}^H
\end{aligned}
$$

![单步权重与维度](../../../source/学术/01-Attention%20Is%20All%20You%20Need-Google/RNN/02-前向传播与多层堆叠/03_矩阵与张量.png)

- $W_x$：当前输入的线性变换参数。第一层输入尺寸一般为 $E$，其他层可能为 $H$。
- $W_h$：上一隐藏状态到当前隐藏空间的变换参数。
- $b$：偏置。
- $f=\tanh$：非线性激活函数，经典 Vanilla RNN 常用，也有 ReLU 变种。
- $h_0$：初始隐藏状态，常初始化为零，也可以由其他网络提供。

### 权重共享和串行依赖

**同一层、不同时间步复用同一组 $W_x$、$W_h$ 和 $b$；不同层通常使用各自独立的参数。** 这不是每遇到一个 Token 就训练出一套新的矩阵。

因为 $h_t$ 必须依赖 $h_{t-1}$，所以单条序列在**时间步方向**存在数据依赖，不能像 Transformer 训练中的矩阵化 Self-Attention 那样同时获得各时刻的状态。值得区分的是：RNN 仍可以并行处理多个 Batch 样本，也可以并行执行单个时间步内部的矩阵运算。

## 4. 多层 RNN：横向时间步与纵向网络层

RNN 完全可以堆叠多层。第 $l$ 层在时间 $t$ 的隐藏状态为：

$$
h_t^{(l)}=\tanh\left(W_x^{(l)}h_t^{(l-1)}+W_h^{(l)}h_{t-1}^{(l)}+b^{(l)}\right),\quad h_t^{(0)}=x_t
$$

![多层 RNN](../../../source/学术/01-Attention%20Is%20All%20You%20Need-Google/RNN/02-前向传播与多层堆叠/04_多层RNN.png)

图中有两类依赖：

1. **横向时间方向：** 同层的 $h_t^{(l)}$ 依赖 $h_{t-1}^{(l)}$，即循环状态递推。
2. **纵向层方向：** 上层的 $h_t^{(l)}$ 依赖下层同一时间步的 $h_t^{(l-1)}$，即逐层特征变换。

各层通常重复同一类计算逻辑，但**每层各有独立权重**；这也解释了"多层"的含义。层数加深提高表达能力，并不保证所有历史细节都被保留。

### PyTorch 最小示例

```python
import torch
import torch.nn as nn

V, E, H, L = 32000, 512, 1024, 3
embedding = nn.Embedding(V, E)
rnn = nn.RNN(input_size=E, hidden_size=H, num_layers=L,
             nonlinearity="tanh", batch_first=True)
lm_head = nn.Linear(H, V)

ids = torch.randint(0, V, (2, 8))  # [B=2, S=8]
x = embedding(ids)                 # [2, 8, 512]
y, h_n = rnn(x)                    # y: [2, 8, 1024]
                                    # h_n: [3, 2, 1024]
logits = lm_head(y)                # [2, 8, 32000]
next_logits = logits[:, -1, :]     # [2, 32000]
```

这里 $h_n$ 表示**每一层的最后时间步状态**，而 $y$ 包含**顶层全部时间步的输出**。二者含义不同。
