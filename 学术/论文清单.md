# 论文阅读清单

> 目标：围绕 AI Infra、LLM 推理系统、CUDA Kernel、模型并行与经典 AI 发展脉络，建立系统化阅读路径。

---

## 一、AI Infra / 推理系统方向

### 1. LLM Serving


| 论文                  | 关键词                          | 阅读目的                         |
| ----------------------- | --------------------------------- | ---------------------------------- |
| Orca                  | Continuous Batching, Scheduling | 理解现代 LLM Serving 调度基础    |
| vLLM / PagedAttention | KV Cache, 显存管理              | 理解 KV Cache 分页管理机制       |
| SGLang                | RadixAttention, Runtime         | 理解 SGLang 的执行与缓存复用思想 |
| Sarathi-Serve         | Chunked Prefill, PD 干扰        | 理解 Prefill/Decode 干扰问题     |
| DistServe             | PD 分离, Goodput                | 理解 Prefill/Decode 解耦架构     |
| Splitwise             | Phase Splitting                 | 理解阶段拆分式推理服务           |
| Mooncake              | KVCache-centric                 | 理解以 KV Cache 为中心的服务架构 |

| FlashDecoding / FlashInfer | Decode Attention            | 理解 Decode 阶段 Attention 优化  |
| Triton                     | Kernel DSL, Tile            | 理解高层 GPU Kernel 编程方式     |
